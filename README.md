# Shift & Fuel Profitability Tracker

A full-stack web application built with Python, Flask, and SQLite to track delivery shift earnings after fuel expenses, featuring an AI-assisted efficiency analyzer.

## Tech Stack
- **Backend:** Python, Flask, SQLite3
- **Frontend:** Vanilla HTML5, CSS3, JavaScript (Fetch API)
- **AI Integration:** Google Gemini API (`gemini-2.5-flash`) with deterministic statistical fallback
